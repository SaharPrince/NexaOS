# NCE-001: Nexa PE Inspector

## Objective

Create a read-only command-line utility that reports structural metadata from
Windows Portable Executable files. Inspection must never execute the input file.

## Supported initial scope

- DOS signature and PE header location
- COFF machine and section count
- PE32 and PE32+ optional headers
- Image base, entry-point RVA, and subsystem
- Section table
- Up to the first 16 standard data directories
- Import library and named/ordinal import metadata
- Named export metadata
- Base-relocation block and entry counts
- Human-readable and JSON reports

## Safety requirements

- Every file read is bounds-checked.
- Every non-empty section raw-data range is checked against the input file length.
- Integer offset arithmetic is checked where it can overflow.
- Section counts and metadata iteration are capped.
- Invalid and unsupported input returns a structured error.
- The inspector never maps a PE image into executable memory or calls its entry point.
- No Windows DLL is loaded as part of inspection.

## Acceptance criteria

1. `cargo test --workspace` passes.
2. A valid PE32+ AMD64 fixture is identified correctly.
3. Truncated and malformed headers fail cleanly without panicking.
4. Section metadata is reported from the section table.
5. Import/export metadata is reported when directories are present.
6. JSON output is valid JSON.
7. The CLI explicitly reports that execution was not attempted.

## Known limitations in this first implementation

- The parser is an initial implementation and requires broader real-world fixture
  coverage and fuzz testing before being treated as hardened.
- Synthetic fixtures cover PE32+ AMD64 and PE32 x86 optional-header parsing; broader real-world PE32 coverage is still required.
- Bound imports, delay-load edge cases, forwarded exports, certificates, and every
  architecture-specific detail are not yet fully interpreted.
- This milestone does not load or run programs.

## Commands

```sh
cargo test --workspace
cargo run -p nexa-inspect -- inspect ./sample.exe
cargo run -p nexa-inspect -- inspect --json ./sample.exe
```
